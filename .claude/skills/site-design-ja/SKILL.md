# サイトのデザイン（日本語・研究者サイト版）

元にしたのは次の 2 つ（どちらも MIT ライセンス）。本文は `references/` にそのまま置いてある。

- `references/redesign-audit.md` … [elayadesign/redesign-skill](https://github.com/elayadesign/redesign-skill) の `redesign-existing-projects`。既存サイトの監査項目と直す順番
- `references/visual-system.md` … [elayadesign/ai-design-skills](https://github.com/elayadesign/ai-design-skills) の `landing-page-design` の Part B（見た目の規則）

## 使い方

1. **監査**するときは `references/redesign-audit.md` の項目で点検し、**直す前に**診断の一覧を先生に見せて、不要な項目を外してもらう。
2. **値**は、元ファイルの「Design values」ではなく、下の「このサイトの値」を使う。元ファイルと食い違ったら、このファイルが優先する。
3. **読み替え**の節にある規則は、元ファイルの対応する規則を置き換える。
4. 直したら、デスクトップ（1440×900）とモバイル（390×844）で実際に撮影して確かめる（`award-quality-web` の撮影→採点→直す）。

## 読み替え（元の規則との違い）

### 書体
- 元の規則は「1 サイト 1 書体」。Geist などには和文の字がないので、**欧文 1 書体＋和文 1 書体の組**を 1 書体と数える。
- `font-family: "Geist", "Noto Sans JP", sans-serif;` の順に書く（英数字が Geist、仮名・漢字が Noto Sans JP になる）。
- Geist Mono は、数字・年・小さなラベルにだけ使ってよい。
- Inter・Roboto・Arial・Open Sans・Helvetica は使わない。斜体は使わない。太さは 700 まで。

### 文字の大きさと行送り
- 大きさは Tailwind の段階（12・14・16・18・20・24・30・36・48・60・72・96・128px）だけ。`clamp()` や中間の値は使わない。画面幅で変えるときは段階ごと切り替える。
- **和文の本文は行送りを広げてよい**（元の規則は段階に付いた行送りのまま）。本文 16px は行送り 28px（1.75）、18px は 32px。和文は字面が大きく、元の行送りでは詰まって読みにくいため。
- 見出しは段階の行送りのまま。ただし和文の大きな文字が 2 行以上になるとき（研究室が目指す社会の一文、研究の考え方）は 1.3〜1.8 に広げてよい。`font-feature-settings: "palt"` で約物と仮名を詰める。
- 和文の本文は `letter-spacing: 0.04em`。欧文（`:lang(en)`）は 0、欧文の大きな名前は -0.02em。

### 和文組版
- 見出し：`word-break: auto-phrase; text-wrap: balance;`
- 本文：`text-wrap: pretty; line-break: strict; letter-spacing: 0.04em;`、1 行 35〜45 字（`max-inline-size: 40em` 前後）
- キャッチコピーなど大事な行は `<wbr>` で文節の切れ目を指定する。単語や文節の途中で折れた見出しは直す。
- 元の規則「文中にハイフンを使わない」は、和文では「区切りに — や ― を使わない（読点か改行にする）」と読む。
- 元の規則「Sentence case」は英語ページにだけ当てはめる。
- 英語ページでは、複合語（user-sovereign など）と固有名（Graph-Document、Privacy-by-Design）のハイフンは残す。取ると英語として誤りになるため。

### 戦略（landing-page-design の Part A）
研究者のサイトなので、次は**使わない**。使うと実在しない実績や声を作ることになる。
- FAQ・推薦文・お客様の声・リスク反転（無料体験・返金など）・価格表
- 架空の社名・人名・ロゴ、「丸すぎない数字」の創作
- 数字と固有名詞は、このサイトの既存の記述・研究室HP・researchmap にあるものだけを使う。

使うもの：
- **主な行き先を 1 つに決める**。このサイトは「研究室HP」が主、「researchmap」が次。連絡先は個人サイトのお問い合わせ（下の値）。
- ボタンの名前には行き先を書く（「研究室のサイトを見る」）。「詳しく見る」「Learn more」だけのボタンは作らない。

### 画像
- picsum などの仮画像は使わない。先生の写真は本物を使う。
- 生成画像は挿絵に限る。人物・実績・作品そのものを表す画像には使わない。

### 仕組み
- 本文は静的な HTML に書き、JS で差し込まない。研究室HPの「AI に聞く」が、このサイトを AI に読ませる参照先になっているため。
- 元の規則「フレームワークを移行しない」の例外：2026-10 の作り直しで、Jekyll の既定テーマ（primer）から自前のレイアウト（`_layouts/home.html`）と本文データ（`_data/ja.yml`・`_data/en.yml`）に替えた。Jekyll 自体は続けて使う。

## このサイトの見せ方（2026-10 に決めたこと）

- コンセプトは「三拍子のスコア」。brightwaltz の「ワルツ」と、研究室HPのヒーロー図解の 3 拍子の脈動にそろえ、研究・社会実装・音楽を 1・2・3 拍目として並べる。
- 見せ場は、ヒーローの下の五線（3/4 の拍子記号と四分音符）。音符が 1 拍 1 秒で進み、その拍の番号が灯る。「拍を鳴らす」は押したときだけ鳴る。
- 節の目印は三つの点（いまの拍を塗る）。最後のクラウドファンディングは「Coda」と複縦線。
- 新しい節を足すときも、この目印の体系に合わせる。拍を 4 つ目に増やさない。

## このサイトの値

**書体**：Geist（欧文）＋ Noto Sans JP（和文）。数字とラベルに Geist Mono。太さ 400・500・600・700。

**地と文字**（明るい地。灰色は少し暖かい系統で統一）

| 役割 | 値 |
|---|---|
| 背景 | `#F7F7F4` |
| 面（カードなど） | `#EEEEE9` |
| 罫線 | `#DAD9D3` |
| 文字 | `#161616` |
| 弱い文字 | `#5C5C57` |

**アクセント**：1 色だけ。玉川ネイビー `#0B2C5C`（研究室HPの `--c-primary` と同じ）。押せる面の hover は `#133B73`。

**ヒーロー見出し**：左から右へ `#000000` → `#666666` の文字グラデーション。グラデーションはここだけで、背景には使わない。

**質感**：平らな面に SVG のノイズを 4% ほど重ねてよい。グラデーションで質感を出さない。

**影**：背景の色に寄せた薄い影 `0 1px 2px rgb(40 38 30 / 0.06), 0 8px 24px rgb(40 38 30 / 0.06)`。カードは背景色の差で分け、枠線と影を両方付けない。

**余白**：0・2・4・8・12・16・24・32・40・48・64・80・96px。主なボタンは上下 8px・左右 12px（ヒーローの主ボタンは 12px・16px）。

**角丸**：Tailwind の値だけ。カード 16px（`rounded-2xl`）、写真 24px（`rounded-3xl`）。内側の角丸は「外の角丸 − すき間」（すき間 32px 未満、結果が 2 を超えるときだけ）。

**幅**：本文の器 1200px。ヒーローの見出しと導入文は 680px まで。

**アイコン**：Phosphor（Regular、線の太さをそろえる）。SVG をページに直接書く。

**動き**：基本の曲線 `cubic-bezier(0.22, 1, 0.36, 1)`。位置の変化 500ms、色と不透明度 300ms（200ms 未満にしない）。スクロールで現れる節は 32px 上がりながら 700ms で現れ、1 回だけ。`transform` と `opacity` だけを動かす。`prefers-reduced-motion` では動かさず、そのまま表示する。
